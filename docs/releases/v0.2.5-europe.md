New: the European PS2 release, SLES-54622 (experimental)

- The launcher now accepts the European/Australian release of Vice City Stories as well as the USA release. It verifies the executable before building.
- The European game gets its own recompiled code and VU1 programs from your own disc. Switching between USA and European discs rebuilds the matching version.
- The European version has been checked on Windows through the opening and initial gameplay. The radio wheel, trainer, mouse camera, widescreen haze and helicopter timing use matched European addresses, but the mission and complete-game coverage is still experimental.
- Linux support for the European build has not been tested in gameplay. The release workflow can produce the Linux launcher when it is available.

Launcher

- The launcher checks this fork's `main` branch for updates at startup by default. The setting can be turned off.
- **Update now** retrieves a newer commit only when it can advance cleanly, then rebuilds the game for the selected disc and stages the updated launcher. Local uncommitted changes stop the update.
- The disc screen identifies the European release and marks it as experimental.

Upstream fixes included

- The mouse wheel changes radio stations while driving.
- Purple Haze no longer remains on "Loading..." above 30 fps, and its haze fills a widescreen picture.
- The mouse camera no longer remains stuck at a wall while on foot.
- The upstream RSL memory limit is included. The current European rendering path does not use that RSL path, so its US memory measurements do not yet apply to the PAL build.
- Helicopter rotor damage follows the original game's rate at high frame rates.
- F12 is left to screenshot and recording software.
- The graphics card can be selected by name, with the dedicated card preferred by default.

Updating

- Extract this release into a short local folder, start `VCSLauncher.exe`, choose your own USA or European disc and build the game. No game code or game data is included.
- Existing saves are kept outside the release folder. The first build after an update can take several minutes; later builds only compile changed files.
- On Linux, download the AppImage when it appears on this release. European gameplay testing on Linux is still needed.
