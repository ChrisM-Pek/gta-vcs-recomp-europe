New: high-resolution HUD textures

- The HUD, the game's texts, the radar and the pause menu can now be drawn from a high-resolution texture pack instead of the PS2's own art. Before, those parts stayed at the original 640x448 resolution however high the game's resolution was set, so the clock, the money, the subtitles and the menu's text grew blurry with the rest of the picture.
- Packs made for PCSX2 are recognised as they are, without conversion: unzip one next to the game (a `textures` folder beside `vcs.exe`), start the game, then in the game's settings (F2) -> Graphics -> Image quality -> **HD textures (HUD)** choose **HD pack**. The default stays **PS2 (original)**.
- A pack can replace the texts and menus' font, the clock and money digits, the radar's ring, compass letters and player arrow, the PlayStation button icons and several pause-menu drawings. Anything the pack does not contain keeps the PS2's art.
- The position of each element is unchanged: the HUD keeps the original layout and only its image gets sharper.
- The first time a texture appears the game reads its file, so the pause menu can hesitate for a moment the first time it opens. Images larger than eight times the original or 2048 pixels a side are scaled down.
- No pack is included: the artwork belongs to the pack's author. Without one, the game is exactly as before.
- A tool in the repository exports the game's HUD textures under the names those packs use, so the remaining elements can be upscaled or redrawn too.

Updating

- Extract this release into a short local folder, start `VCSLauncher.exe`, choose your own USA or European disc and build the game. No game code or game data is included.
- Existing saves are kept outside the release folder. The first build after an update can take several minutes; later builds only compile changed files.
- On Linux, download the AppImage when it appears on this release.
