Mods: HD textures from the launcher

- The launcher has a new **Mods** tab in its title bar, next to Saves and Settings. It links the community *HD HUD* pack's page on GTAForums: download it there, then **Install a pack...** with the pack's `.zip` or `.7z`. The launcher puts the textures where the game reads them and turns the game's Graphics > Image quality > **HD textures (HUD)** setting on, so the next start shows the sharp HUD, texts, radar and menus.
- Before, the pack had to be unzipped next to the game by hand and the setting found in the game's menu.
- **Remove the textures** puts the PS2's art back. Close the game while the pack is installed or removed.
- The pack belongs to its author and is not included: the Mods tab opens its page in the browser. Without a pack the game is exactly as before.

Updating

- Extract this release into a short local folder, start `VCSLauncher.exe`, choose your own USA or European disc and build the game. No game code or game data is included.
- Existing saves are kept outside the release folder. The first build after an update can take several minutes; later builds only compile changed files.
- On Linux, download the AppImage when it appears on this release.
