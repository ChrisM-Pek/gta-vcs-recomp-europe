Fix: the HD HUD no longer freezes when it shows something for the first time

- With an HD texture pack, the picture could stop for a moment (a tenth of a second, more for the biggest images) each time a HUD element appeared for the first time: a new message, the pause menu, a weapon icon. The pack's images are now read in the background, so that moment costs nothing: the element shows the PS2's art for a frame or two, then switches to its HD image.
- Measured at 60 fps: the pause menu's first opening used to be a 36 ms frame, now 20 ms, where a normal frame is 17 ms.
- The biggest images (the font atlas, the menu's drawings) are read while the game loads, so they do not even show that.

Updating

- Extract this release into a short local folder, start `VCSLauncher.exe`, choose your own USA or European disc and build the game. No game code or game data is included.
- Existing saves are kept outside the release folder. The first build after an update can take several minutes; later builds only compile changed files.
- On Linux, download the AppImage when it appears on this release.
